# CPD for Modern Careers: standalone course

A single-file course (`index.html`): 12 modules, final quiz (80% pass mark) and printable certificate.
It works offline. Progress and quiz results are saved on the learner's own device.

## Publish on GitHub Pages (free)
1. Create a new public repository on GitHub.
2. Upload `index.html` and this README.
3. Go to Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute the course is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before you publish
